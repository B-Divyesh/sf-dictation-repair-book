PRIVACY POLICY

Privacy policy

Effective 29 August 2026

What the app stores

The desktop app stores application labels, explicit before/after transcript corrections, approved rules, settings, and rule-use counts in an AES-256-GCM encrypted vault on your device. It creates a separate local key with restricted file permissions where supported.

What it does not collect

Dictation Repair Book does not record or retain audio, monitor other fields, record typing, run analytics, create an account, or send your glossary to us. Clipboard text is read only after you press a capture button and is not transmitted by the app.

Licenses

If you buy or verify a license, the token is sent to the Sociobot billing API. The app stores the token and a daily verification verdict locally. Repair-book text is never included in that request.

Exports and deletion

You can export CSV, JSON, and Whisper vocabulary at any time. “Erase all local data” deletes the encrypted vault, local encryption key, license token, and cached verdict. Removing the application may leave operating-system application data; use the in-app erase action first.

Website and contact

The website uses no advertising cookies or third-party runtime scripts. Release lookup contacts GitHub to find the latest installer. Questions can be filed in the public issue tracker.
