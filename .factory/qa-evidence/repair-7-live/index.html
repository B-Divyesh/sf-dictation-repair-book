PRODUCT LIMITS

Before you install

Does it record or transcribe audio?

No. It repairs transcript text from dictation tools you already use. Audio never enters the app.

Does it watch everything I type?

No. You opt in to named source applications and click “Paste clipboard” for each capture. v0.1 does not monitor fields or keystrokes.

Which engines does it support?

Paste text from your dictation tool, then run approved replacements locally. Exports include CSV, JSON backup, and a vocabulary prompt for Whisper-compatible workflows.

Can I export and delete my data?

Yes. Exports are never paywalled. You can erase the encrypted vault and its local key at any time.
